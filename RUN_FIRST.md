# Seminar Registration System (MERN)

1. Install Node.js 18+ and MongoDB (or use MongoDB Atlas).
2. Backend: `cd backend && npm install && cp .env.example .env && npm run seed && npm run dev`
3. Frontend (new terminal): `cd frontend && npm install && npm run dev`
4. Open http://localhost:5173 and log in with a demo account (see backend/README.md).
